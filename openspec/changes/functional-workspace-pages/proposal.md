# Proposal
## Why
用户明确要求机器查看配置按功能分页签，模板查看配置沿用注册布局并避免撑开页面；任务查询与评测提交、批次结果需要清晰分工。
## What Changes
- 机器详情内部按功能分为基础、Agent、升级、宿主机、容器、存储、保留和服务网络页签。
- 模板详情复用注册表单，以只读形式展示，长文本和窄屏不横向撑开页面。
- 我的任务仅查询；CS 评测批次改名业务评测向导，仅发起评测；其下新增评测运行与结果，按批次查看参数、服务和任务状态、结果。
- 原集合管理和客户端接入移至管理设置；普通成员保留自己的评测配置入口。
## Capabilities
### New Capabilities
- `workspace-navigation`: 任务提交、查询和配置的功能边界及页内展示。
### Modified Capabilities
无。
## Impact
仅 React 前端与浏览器测试；复用现有任务、编排和配置 API。不修改调度、运行快照或权限接口。
