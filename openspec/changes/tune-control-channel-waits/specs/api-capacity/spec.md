## ADDED Requirements

### Requirement: 等待配置有对照与复验
系统 SHALL 用相同负载比较等待配置并保留成功、失败与剩余竞争，不以扩大超时伪装吞吐提升。

#### Scenario: 提高执行控制等待
- **WHEN** 将执行控制入口与连接等待各设置为1秒
- **THEN** 校验仍在4秒SQL和5秒HTTP预算内，并比较心跳503与成功延迟；无收益时不推荐改大

#### Scenario: 发布候选配置
- **WHEN** 选择等待配置更新部署
- **THEN** 先通过混合专项复验，记录有限测试边界、同步配置示例和文档，并保留回滚路径
