# Proposal

## Why

托管服务批次在默认的“任务与结果”页只显示客户端状态。服务实例未创建时，服务页也没有服务端候选设备和阻塞原因，用户无法判断服务端正在等待调度、缺少环境，还是已经启动并等待健康检查。

## What Changes

- 编排详情为尚未创建实例的服务定义返回只读服务端候选设备诊断及资源池名称。
- 默认任务页显示服务端调度、启动与健康状态；完整候选设备阻塞原因、探测详情和日志仍可展开或进入服务页查看。
- 保留现有权限、调度和预留语义；诊断不触发资源预留。

## Impact

涉及编排详情 API、批次详情 UI、界面用户指南、批次监控文档及项目 Skill 参考索引。无数据库迁移或 Worker 协议变更。
