# Proposal

## Why

用户有多台局域网 GPU 主机，需要接入已启动的本机平台统一查看资源和调度评测。现有 Worker、资源池及目录配置功能已经实现，本次落地真实多机部署并记录验收。

## What Changes

- 本机控制节点保留回环浏览器访问，同时开放指定 Wi-Fi 私网地址供 Worker 连接。
- 核对 5 台远程机器与本机；可达且运行环境合格的节点安装独立凭据 Worker，加入一个异构公共池。
- 补齐三台新节点 Docker/NVIDIA 容器运行环境；保留已有 NVIDIA 驱动。
- 配置持久工作/资产/缓存目录、开机服务，保护已有执行记录和旧部署配置。
- 用真实 GPU 容器与小型平台任务验证注册、资源分配、结果及队列，记录离线节点的后续接入步骤。

## Capabilities

### New Capabilities

无新增产品契约。本次是使用已有 API、安装器、Worker 的部署与运维文档变更，设置 skip_specs: true。

### Modified Capabilities

无现有 API/调度/数据模型行为修改。

## Impact

涉及本机 192.168.8.151、远程 .182/.177/.183/.157；.174 不可达，记录为待接入，不伪造在线状态。不迁移 R8000 旧控制库，不保存 sudo 密码到仓库；Worker 配置含 token，使用 0600。开发与部署文档纳入 Git，运行凭据和日志留在忽略目录。
