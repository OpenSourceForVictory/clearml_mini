## Why

平台通过设备槽位 claim 把 `device_index`、`gpu_uuid` 下发给该卡 Worker。NPU 宿主机启动前已核对节点配置和设备稳定标识；GPU 宿主机原先仅把任务里的 UUID 写入环境变量，缺少本机复核。节点设备更换或异常任务快照可能导致实际业务卡与平台预约卡不一致。

## What Changes

- GPU 宿主机任务在创建启动记录前，核对下发设备编号与该 Worker 的本机编号，并读取当前 GPU UUID 核对稳定标识。
- 不匹配或设备身份读取失败时拒绝启动，保留现有任务失败与清理流程；虚拟设备和 NPU 原有路径保持不变。
- 增加匹配、编号错误、UUID 错误及读取失败测试，更新宿主机运行说明。

## Impact

Worker GPU 宿主机启动前准入；不改变平台调度、claim 协议、容器分配或 GPU 内核隔离能力。
