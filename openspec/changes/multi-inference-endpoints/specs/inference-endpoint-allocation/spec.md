# Spec Delta

## Purpose

允许用户在一次评测运行中直接配置多个推理地址及各地址独占或共享模式，由平台将仿真客户端任务与可用地址绑定，统一处理等待、执行恢复和实际使用地址的追溯，无需注册服务池。

## ADDED Requirements

### Requirement: 运行级地址列表
系统 SHALL 接受 1–100 个包含 URL 和 exclusive/shared 模式的推理地址作为运行配置。列表每项遵守已有地址安全校验和模板协议限制，同一规范主机端口不得重复；列表与旧单地址参数同时出现时拒绝请求。地址不要求预先注册。

#### Scenario: 地址列表提交
- **WHEN** 用户提交 A 独占、B 共享的有效列表
- **THEN** 系统保存不可变候选配置，任务先入库等待分配，不创建推理服务池

#### Scenario: 无效或重复地址
- **WHEN** 地址为空、超过 100 项、模式无效、协议不兼容或规范主机端口重复
- **THEN** 系统返回具体字段错误，不创建部分批次或任务

### Requirement: 旧单地址兼容
系统 SHALL 保留旧 endpoint 请求及历史快照行为，使用模板 endpoint_exclusive 决定其模式；显式列表中的模式优先于模板旧默认值。旧 Worker SHALL 仍获得含一个具体 endpoint 的执行输入。

#### Scenario: Cosmos 旧默认与显式共享
- **WHEN** 用户采用旧单地址请求且模板为独占
- **THEN** 系统沿用独占；当用户改为显式共享列表时使用该显式模式，并在界面说明共享要求服务端支持多会话

### Requirement: 联合分配与等待
系统 SHALL 在同一调度决策中满足客户端资源和推理地址准入要求后分配执行。地址优先选择当前占用较少的合格项，同负载按输入顺序；无合格地址或无 Worker 资源时保留排队，不占用另一方资源。预检仅解释候选可用性，不预留地址。

#### Scenario: 两个独占地址并发
- **WHEN** A、B 均空闲且有两个满足资源条件的客户端槽位和两个任务
- **THEN** 平台分别分配 A、B；第三个任务等待地址释放

#### Scenario: 首地址忙碌
- **WHEN** A 被互斥任务占用而 B 合格
- **THEN** 系统选择 B，不因为列表第一项忙碌而阻塞全部候选

### Requirement: 跨运行的独占共享互斥
系统 SHALL 按规范主机名与端口统一检查所有用户和集合的已预留或未完成清理的执行。仅当候选及现有占用都为 shared 时允许重叠；任一为 exclusive 时禁止重叠。独占优先表示冲突判定，不抢占运行中的共享任务，也不增加任务队列优先级。

#### Scenario: 混合模式冲突
- **WHEN** 同一地址已有共享任务，另一集合请求独占使用
- **THEN** 独占任务等待现有共享占用全部释放，其他合格地址仍可被选择

#### Scenario: 共享访问
- **WHEN** 多个任务选择同一 shared 地址且客户端与运行并发额度允许
- **THEN** 系统允许并发，不要求配置额外的服务并发额度

### Requirement: 尝试绑定及恢复
系统 SHALL 将实际地址和模式持久绑定到执行尝试。认领重放和 Worker 重启沿用该绑定，不在执行中透明切换服务。终态仍有未确认容器清理时继续持有端点；未领取预留失效时释放；新尝试可以重新分配且旧记录保持不变。

#### Scenario: 断线与重试
- **WHEN** 使用 A 的尝试断线后恢复，随后失败并完成清理，用户发起重试
- **THEN** 恢复仍使用 A，新尝试可选择 B，历史记录分别保留 A 与 B

#### Scenario: 取消或暂停预留
- **WHEN** 尚未认领的任务预留被取消、暂停或因资源配置切换撤回
- **THEN** 系统同时释放 GPU 预留与地址占用，后续调度重新分配

### Requirement: 界面配置及结果追溯
系统 SHALL 提供地址列表增删、独占/共享选择、字段错误提示及运行确认摘要。轮询不得覆盖草稿，提交响应丢失后的重放不得扩大或改变配置。任务详情、批次监控、报告和导出 SHALL 区分候选列表与各尝试实际地址；未分配时显示未分配，并沿用任务所有权权限。

#### Scenario: 结果展示与比较
- **WHEN** 两次运行候选列表相同但实际选择地址不同
- **THEN** 报告记录实际地址差异，不把候选第一项冒充执行地址，不根据相同地址推断相同模型版本

#### Scenario: 草稿与迟到响应
- **WHEN** 用户编辑多个地址，轮询更新或上次预检响应迟到
- **THEN** 草稿保持，过期预检不得覆盖新配置对应的结果
