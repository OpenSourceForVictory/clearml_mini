## Purpose

将机器接入平台与 GPU 分配资源池分开，允许管理员依据已发现的设备灵活组织异构资源，并在成员变更、离线和重连时保持任务执行、资源记账和界面状态一致。

## ADDED Requirements

### Requirement: 无资源池纳管
平台 SHALL 接受经过机器凭据认证但未指定资源池的设备注册，保留设备身份和心跳，未分配设备不得获得新任务。

#### Scenario: 先接入后建池
- **WHEN** 新机器在没有任何资源池时注册 GPU
- **THEN** 管理员能看到该机器及未分配的 GPU，注册成功不等于开始执行任务

### Requirement: 接入配置与多卡安装
平台 SHALL 允许管理员明确配置 Worker 可访问的 API 地址和设备类型，安装工具 SHALL 检查连通性并支持一次选择多张 GPU 安装独立实例。

#### Scenario: 浏览器通过隧道访问
- **WHEN** 管理员从回环地址打开平台并生成接入配置
- **THEN** 页面明确要求确认 Worker 接入地址，不把浏览器回环地址无提示地作为正确地址，真实 GPU 接入不默认启用模拟设备

#### Scenario: 多卡机器首次接入
- **WHEN** 机器管理员选择全部可发现 GPU 或一组明确的 GPU 编号安装
- **THEN** 每卡建立独立配置与恢复记录，不要求事先选择资源池，不覆盖其他实例的状态

### Requirement: GPU 单池归属与异构池
平台 SHALL 以 GPU 槽位作为池成员，同一槽位同时最多有一个实际资源池，允许跨机器混合型号及同机不同卡分属不同池。

#### Scenario: 整机或部分卡加入
- **WHEN** 管理员选择整机已登记设备或部分 GPU 加入一个池
- **THEN** 仅选中的设备参与变更，界面明确操作范围，机器 CPU/内存及并发额度在各池之间合计计算

### Requirement: 管理员版本化批量成员操作
平台 SHALL 限制成员变更为管理员操作，检查设备、目标池及配置版本，并对批量请求提供原子接受或整体拒绝及逐项原因。

#### Scenario: 批量中包含不兼容设备
- **WHEN** 目标池不存在、未启用、设备类型或显存不符合要求，或任一成员版本过期
- **THEN** 整批不产生部分写入，界面指出需修正的设备或版本，不能强制覆盖并发修改

### Requirement: 排空后移除与迁移
平台 SHALL 在移除或换池时立即停止相关设备的新准入，释放未领取预留，在已领取任务及遗留清理完成后才改变实际归属。

#### Scenario: 任务运行中换池
- **WHEN** 管理员将正在运行任务的 GPU 从池 A 移至池 B
- **THEN** 设备显示从 A 到 B 的排空状态，原任务继续在 A 的执行记录下完成，B 在清理确认前不能使用该设备

#### Scenario: 移除与领取竞争
- **WHEN** 移除成员与 Worker 领取任务并发发生
- **THEN** 任务要么作为已领取执行保留，要么退回原池队列，不丢失执行身份，不重复预留资源

#### Scenario: 离线执行尚未清理
- **WHEN** 设备离线且存在未确认清理的执行
- **THEN** 排空持续等待，不因离线或超时自动释放到目标池，原执行仍能续租、恢复或上报清理

### Requirement: 重连保留平台归属
平台 SHALL 让管理员已管理的设备归属以平台配置为准，重连和 Worker 重启不得用本地旧资源池配置覆盖该归属。

#### Scenario: 已移除设备携带旧 pool_id 重连
- **WHEN** 一个已由管理员移出池的 Worker 携带旧 pool_id 重新注册
- **THEN** 设备仍为未分配，继续上报心跳但不自动重新加入原池

#### Scenario: 未经平台调整的旧设备
- **WHEN** 既有 Worker 以旧配置继续注册且管理员尚未管理其归属
- **THEN** 原有资源池和注册行为保持兼容，升级数据库不会移动设备

### Requirement: 资源池成员与可用性展示
平台 SHALL 展示当前及期望成员关系、变更进度、池内 GPU 型号分布、设备数量和任务统计，分开表达连接状态、成员状态及准入阻塞。

#### Scenario: 在线但不能接单
- **WHEN** GPU 在线但未分配、正在排空、存储未确认、磁盘不足或等待遗留清理
- **THEN** 页面给出具体状态或原因，不仅显示正常；就绪数量不代表一定满足任意客户端任务的镜像或资源要求

#### Scenario: 设备重连及部分迁移完成
- **WHEN** 同一批设备中部分已迁移、其他仍离线或排空
- **THEN** 页面逐卡显示实际归属，离线不会删除成员，池统计不把同一张卡同时计入两个池的现有资源
