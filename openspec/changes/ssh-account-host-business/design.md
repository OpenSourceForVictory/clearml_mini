# 设计

SSH 表单和独立执行器将 `username` 作为 `business_user` 传递到只读探测与安装凭据。新系统安装仍要求 root SSH；安装器验证 root UID/GID 为 0/0。生成的每张卡配置将 `host_execution` 和 NPU host identity 绑定到该账号，Worker 以该身份读取登录 Shell 环境并启动宿主机业务。

已有安装和重新纳管继续沿用原配置，不自动切换身份。Docker 业务不读取此字段。

SSH 表单可传入工作目录根路径。探测按 `根路径/机器名/gpuN` 或 `根路径/机器名/npuN` 预览各设备工作目录。资产和缓存由同一机器各卡共享，分别使用 `根路径/机器名/assets` 和 `根路径/机器名/cache`。安装器复核绝对路径、已有父目录访问权限与实际设备清单，创建缺失目录；每卡工作目录下的 `runs` 独立。已有目录及内容不递归改属主；重新纳管保留原路径，不自动搬迁已有每卡资产和缓存。Docker 的原有挂载访问模式不变，共享目录不表示改变读写权限。
