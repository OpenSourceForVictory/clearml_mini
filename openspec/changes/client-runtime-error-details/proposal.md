# 客户端运行环境逐卡错误细化

## 问题

提交预检可能仅显示“客户端运行环境未就绪”或“镜像未批准或未就绪”，无法判断是管理员未批准镜像、节点缺镜像、探测失败，还是运行配置报告过期。Worker 报告原始错误可能包含私有路径，不应直接给任务提交者。

## 方案

复用预检现有逐卡原因区域，从批准配置和 Worker 检查报告生成安全的分类原因及操作建议。只读检查不改变任务准入或提交语义。同步界面指南、调度文档与项目 Skill 参考。

## 验证边界

使用模拟节点报告覆盖批准、缺镜像、探测失败及路径脱敏，并用 mock API 浏览器测试验证显示。真实镜像构建和业务运行不属于本变更的自动化验收。
