# Proposal

## Why

多卡机器的存储设置只有整机表单，且无整机配置时误用 GPU/NPU 0 的实际目录预填。用户保存后会把第 0 卡路径应用到所有卡，也不能分别修改后续设备。

## What Changes

- 保留整机默认配置，新增每卡独立覆盖配置及管理员接口，Worker 心跳按槽位下发。
- 界面将整机默认与逐卡编辑分开，显示机器名和设备编号的建议路径、实际槽位后缀及逐卡生效状态。
- 修正无整机配置时的误导性预填；保留旧目录和执行恢复语义。

## Impact

涉及存储 API、Worker 心跳配置解析、机器存储界面、用户指南和运维文档。复用现有 JSON 元数据，无数据库迁移或 Worker 协议变更。
