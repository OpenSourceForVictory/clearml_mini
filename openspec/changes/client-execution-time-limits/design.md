## Decisions
GET /api/v1/execution-limits 登录可读返回 client_execution_max_seconds 与默认请求值 min(300,max)。客户端 timeout_seconds 为正整数；snapshot 对当前上限再次校验并明确输出申请和上限，避免 UI 数据过期绕过。拒绝超过上限不静默截断。已保存客户端 snapshot 时限不因环境变量改变缩短，旧无 client_spec 任务仍使用平台默认。服务端持续运行语义不变。
向导请求上限失败时展示失败/重试，不允许提交；新加载时默认值收敛到上限，用户编辑后的数值不静默调整。显示覆盖全部回合且不是逐回合时限。reconcile 优先标出总执行超时，其次启动超时，最后租约；保留清理确认与隔离。
## Validation
上限大于3600、等于上限、超限、非法数值、配置缩小不影响存量、鉴权、三类超时及清理、UI读取上限/错误/重试和实际提交值。只专项测试，不跑全量覆盖率。
