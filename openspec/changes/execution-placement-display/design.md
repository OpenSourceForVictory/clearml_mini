## Decisions
placement 为可空对象，使用最新 Run.slot_id 而非目标槽位；Slot 被软删除时仍可展示历史位置，找不到时返回 null。批次按槽位 ID 批量读取，避免每个任务增加查询。服务根据当前 job 最新 run 读取，空尝试或尚未分配不回退到 instance.slot_id。
统一展示节点、GPU/NPU 卡号和型号；位置表示资源分配，结合独立状态区分预约/运行/结束，不把位置当作正在运行的证据。外部服务不推测节点硬件。旧 API 没有 placement 时提示位置不可用；明确 null 提示未分配或记录不可用。
## Validation
API GPU/NPU、未分配、重试及历史槽位；浏览器默认页和关联页服务位置、客户端独立列；相关既有测试，不运行全量或宣称真机验收。
