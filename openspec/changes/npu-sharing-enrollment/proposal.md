# GPU/NPU 共享批准与双执行环境纳管

当前 SSH 纳管没有 NPU 共享选择，新系统级安装却自动写入 `allow_shared: true`；旧节点重新纳管保留本地值但界面不显示。管理员无法从计划判断共享能力来源，也不能通过受控重新纳管修改。

纳管表单增加明确选择。新安装默认关闭；重新纳管默认保留原值，可显式开启或关闭。检查计划只显示逐卡共享布尔值，安装和回滚保持原有凭据与业务配置保护。资源池共享仍独立配置。

GPU 同样需要设备级共享选择。宿主机和容器改为可同时勾选，新安装同时验证所选环境并写入两个执行方式；现有节点重新纳管保留其原执行方式。旧 GPU 节点未记录设备级批准时沿用原资源池策略，直到管理员明确选择。
