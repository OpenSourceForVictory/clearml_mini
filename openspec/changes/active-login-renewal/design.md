## Context
现有 JWT 仅包含 sub/exp，前端遇到 401 清空用户并卸载表单。登录令牌存储在 sessionStorage。

## Goals / Non-Goals
支持真实用户操作续期、30 分钟闲置、12 小时绝对上限和内存表单恢复。不引入长期 refresh token，不自动重放失败写请求，不持久化表单或 SSH 凭据，不改变节点身份认证。

## Decisions
续期仅接受未过期且包含原登录起点的 JWT，检查账号启用状态并固定原始起点。每次签发 exp=min(now+30m,start+12h)。前端捕获可信 pointerdown/keydown/wheel/touchstart，在可见窗口中最多每分钟发起一次续期；定时器只检查闲置和 token 到期，不触发续期。轮询及程序生成事件不计活跃。令牌到期或 401 后隐藏但不卸载工作台，阻止无凭据 API 请求；同账号且角色不变才恢复。显式退出卸载页面。旧请求响应不能清除或覆盖新令牌。

## Risks / Trade-offs
节流使最后一次交互后的可续期窗口最多比 30 分钟短约一分钟；前端按令牌有效期提前提示。网络失败不立即丢失表单，下一次交互可重试；到期需登录。保留仅限当前页面内存，刷新/关闭页面不会保存表单。页面锁定不是本机内存加密。原始 JWT 不含会话起点，不可续期。客户端活动不是服务端可信的人类证明，绝对时限由服务端执行。

## Migration Plan
发布后新登录签发带会话起点的令牌；原登录仍可使用到到期，但首次续期需要重新登录。无数据库变更。
