# 节点报告有效期与采样周期匹配

## 问题

宿主机环境、容器运行配置、存储和资源采样当前共用 15 秒有效期。Agent 默认每 15 秒采样一次，加上探测、网络和数据库延迟，正常节点也会短暂显示环境或遥测过期并停止新任务准入。

## 方案

将配置回执有效期设为 60 秒，磁盘、GPU/NPU 和 Agent 主机资源采样有效期设为 45 秒，并统一相关管理页面、预检和执行领取检查。Worker 在线与任务租约保持独立，报告版本不匹配、检查失败、未来时间戳和缺失字段仍立即关闭准入。

## 验证边界

隔离测试验证有效期内、过期、未来时间戳和版本变化；不把模拟采样当作真实节点长期稳定性或业务评测验收。按用户要求仅运行相关测试，不运行全量测试。
