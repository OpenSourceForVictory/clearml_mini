# 产物功能验收矩阵

本文件是待实现测试设计，不是测试通过记录。每项需记录实际测试文件、结果、失败/跳过原因；模拟 API、真实系统权限、Docker、GPU/NPU 和浏览器分别标注。

## A. 输出目录与协议（参数化矩阵）
宿主机和 Docker 分别组合 SDK、直接协议、普通命令；每回合启动和整任务启动分别验证。SDK setup 使用任务目录；每回合 context 独立，旧 context 不变；任务输出字段/旧相对路径完全兼容。一个/三个回合、不同 seed、同名文件互不覆盖；SDK-in-per-episode 不重复嵌套。直接协议无声明/一个/多个回合引用/越界回合/无文件声明；普通命令无协议时仍可收集输出，不能把文件数量冒充回合成功数。SDK 异常、非零退出、协议无 final、缺业务文件、后续回合继续及 stop 策略均验证。

## B. 共享目录索引与保留
空目录、中文/空格文件名、嵌套目录、零字节、超过旧 8 MiB 的实际文件、多文件、分页临界；链接根/祖先/叶、换链接、FIFO/设备/套接字拒绝；私有协议文件不索引。扫描中变化、消失、无读权限；Worker 重启恢复历史索引、重复登记幂等。完成/失败/取消与清理竞争，失败不改业务结果；批次删除后迟到登记不可复活。Docker 输出持久挂载，删除容器后仍可读；节点清理后明确已清理。

## C. API 共享存储读取
不主动传文件正文，数据库仅元数据。API 只读挂载、节点/API 不同路径前缀、多个共享根/歧义映射、组件边界（/data/a 不匹配 /data/ab）、历史 storage_id 隔离、挂载缺失/误挂空目录/存储身份变化。Worker 离线但共享存储可用时可读。慢 NFS、超时、取消、并发和 API 多进程/副本；小连接池下心跳/probe 不被文件 I/O 占满；每块内存有界，正文不落数据库、不缓存完整文件。旧 Worker 上传行为能力协商后才改变。

## D. 自定义目录与权限
模板空值/批准共享根内路径/参数映射/缺参数/非法路径/容器持久映射/临时层；快照不受模板后改影响，旧任务不补新路径。实际 API 服务账号读取权限、只读挂载不可写；平台用户跨任务拒绝，即使 API 系统账号能读也不能越权。共享授权撤销、存储映射切换、根变化拒绝。穿越、URL 编码穿越、绝对子路径、链接 TOCTOU、硬链接和特殊文件；有限分页；共享不可用/文件清理/文件替换明确区分。Worker 远端身份 helper 的已有测试作为历史证据，不算当前直读链路验收。

## E. 视频和下载
历史数据库与共享文件分别测试 GET/HEAD；Range 0-0、中段、开区间、尾范围、末字节、越界、空文件、无效/多范围、If-Range 匹配/不匹配；断开/拖动取消旧请求，ETag/Content-Length/Content-Range 完整。真实 MP4/WebM 在 Chromium canplay/seeked，unsupported codec 提示下载；不宣称所有浏览器编码兼容。授权过期/注销/用户停用/跨任务/任务删除/伪造 cookie/撤销共享根授权 均拒绝；HTML/SVG/JS 不内联执行，文件名 header 注入不能成立。连续播放没有整文件 blob 加载或大量 DB 二进制堆积。

## F. 前端
批次按钮、任务详情、回合入口三处打开同一面板；默认最新尝试/历史选择/全部与任务级和回合筛选、共享目录 tab 面包屑、分页、预览/下载。快速切换任务/尝试/回合、旧请求晚到、关闭再打开、轮询不关闭面板；保留列表筛选/滚动/补跑选择。loading/空/失败/索引中/已清理/缺目录配置区分；窄屏/键盘 Escape/焦点回归/屏幕阅读标签；媒体开关与过期授权恢复。

文本预览追加：有效/无效/过深 JSON、折叠展开、超限截断、空文本、UTF-8 多字节边界；CSV 引号/逗号/换行/双引号/不齐列/行列限额；HTML/SVG 不执行；WebP；切文件取消旧读取，授权过期重试，不整文件加载。

## G. 数据库及升级
一次性 PostgreSQL 验证索引迁移、旧 blob 下载和旧 Worker 兼容；删除批次清理关联元数据不触发外键 500，节点文件不冒充集中备份。重启 API 后共享目录历史快照仍可读；回滚不删节点文件。不得用 SQLite 替代 PostgreSQL 迁移和并发验收。

## H. 真机
增加 API 容器只读挂载真实共享目录、节点与 API 路径不同的端到端验证；停止测试 Worker 后仍能预览已有文件，不停共享存储。
实际提交宿主机 SDK 三回合/每回合直接协议/普通命令和 Docker 对照，生成可播放短视频、JSON 和图片，校验 hash、回合归属、同名隔离、下载内容。至少包含真实 GPU/NPU 节点可用性与普通业务账号；仅生成样例文件属于功能验收，不冒称模型评测。保留一个指定平台的验收批次及 URL/ID，用户能在结果页访问；隔离平台测试需说明地址与存续时间。测试只清理自己创建的进程/目录，不更新未授权生产节点。

## 覆盖率
使用 python -m scripts.test_coverage 及 docs/code-coverage.md 同口径，产物采集/执行/结果关键模块目标行90%/分支80%，各目录80%/70%。保留未达标和跳过结果。Playwright 与真机子进程未插桩不计入 Python 覆盖率。阶段提交须同步 API/SDK 指南、界面指南、升级文档和项目 Skill 参考。

## I. 独立根调整
存储配置保存/版本确认/忙等待/旧Worker拒绝；根路径敏感目录/链接/工作目录交叠拒绝。批次与standalone、重试隔离、SDK/普通命令/直接协议、宿主/容器参数和env/input一致；逐回合输出不同而cwd不变。普通账号创建与权限失败；工作目录清理后产物存在；新共享目录登记校验与旧登记兼容。定向统一覆盖率、实际本机子进程与Docker样例不冒称GPU/NPU模型验收。

继承补充：卡级独立工作目录+缺省/null产物根、显式产物覆盖、整机修改/删除、旧配置无产物根、期望配置不修改原始配置；验证心跳下发与错误回执拒绝、界面空值继承提示。
