## Purpose
让用户按评测批次、任务、执行尝试和回合查找生成的结果文件，支持节点产物的按需预览下载及批准节点目录的实时只读浏览，并保证历史兼容、任务权限、文件归属和业务结果独立。

## ADDED Requirements

### Requirement: 产物的任务和回合归属
系统 SHALL 仅自动索引平台输出目录普通文件，并按执行尝试隔离；SDK 与逐回合启动使用已登记的回合目录归属，直接协议使用显式声明，未关联文件归为任务级。
#### Scenario: 同名回合及重试
- **WHEN** 不同回合或执行尝试生成同名视频
- **THEN** 文件分别归属且不会覆盖，用户可以独立查看
#### Scenario: 直接协议无声明
- **WHEN** 单进程直接协议生成文件但未声明回合
- **THEN** 文件归任务级，不根据目录名推断回合

### Requirement: SDK 输出目录兼容
SDK SHALL 保持已有 output_dir 与 artifacts 相对路径语义，新增每回合独立 episode_output_dir，不修改进程全局环境。
#### Scenario: 旧业务及上下文保留
- **WHEN** 旧业务使用 output_dir 或保存前一回合 context
- **THEN** 原路径含义不变且前一回合 context 不随新回合变化
#### Scenario: 包装后的 SDK
- **WHEN** 每回合子进程已经收到回合目录
- **THEN** SDK 不再额外嵌套回合目录

### Requirement: 节点索引独立于业务结果
系统 SHALL 将新文件保留在执行节点，仅登记元数据，不主动上传文件正文；索引与读取失败不得修改业务退出码、回合成功率或重新执行业务。
#### Scenario: 异常退出或节点离线
- **WHEN** 程序异常退出或节点离线
- **THEN** 保留真实业务结果，已有输出仍可索引，读取不可用时显示具体原因
#### Scenario: 容器删除及节点清理
- **WHEN** 新容器被删除或节点输出被清理
- **THEN** 持久挂载输出在容器删除后仍可读取；节点文件清理后显示已清理，不承诺平台备份

### Requirement: 自定义目录只读浏览
系统 SHALL 允许按模板快照配置的目录在执行节点按业务账号权限只读浏览和下载，不自动上传或推断产物归属；容器仅允许批准的持久挂载目录。
#### Scenario: 节点离线或权限不足
- **WHEN** 节点离线、文件不存在、业务账号无权限或批准撤销
- **THEN** 明确显示对应原因，不回退到高权限读取也不展示为空目录
#### Scenario: 路径逃逸及历史配置
- **WHEN** 请求越过批准根、利用链接或历史任务没有配置目录
- **THEN** 拒绝读取，不从当前模板或用户请求补造历史根路径

### Requirement: 授权预览与范围下载
系统 SHALL 对历史数据库产物和节点文件提供鉴权的有界预览与下载；兼容视频支持单范围读取和拖动，未支持编码提供下载，不自动转码。
#### Scenario: 视频范围与文件变化
- **WHEN** 浏览器读取视频范围、请求越界或节点文件被替换
- **THEN** 分别返回正确范围、明确范围错误或文件变化错误，不混合不同版本字节
#### Scenario: 越权或不安全类型
- **WHEN** 用户尝试其他任务文件或预览 HTML/SVG
- **THEN** 拒绝越权，主动内容只能下载，不能作为平台页面执行

### Requirement: 结果侧栏与历史兼容
系统 SHALL 从任务行和回合详情提供产物侧栏，区分平台输出目录及自定义节点目录，支持历史尝试与回合筛选，保留当前页面状态，兼容旧数据库正文下载。
#### Scenario: 切换尝试与延迟响应
- **WHEN** 用户切换任务、尝试、回合或关闭侧栏
- **THEN** 旧请求及播放终止，不混入其他尝试内容，筛选与滚动保留
#### Scenario: 无数据与旧记录
- **WHEN** 加载中、读取失败、没有产物或历史未登记回合
- **THEN** 状态分别说明，历史文件仍可下载且未登记文件归任务级

### Requirement: 通用产物安全预览
系统 SHALL 支持 JSON 格式化折叠、文本、CSV 表格、常用图片及视频预览；文本读取和渲染有界，不整文件加载大型产物。
#### Scenario: 无效或超大文本
- **WHEN** JSON 无法解析或文本超过预览上限
- **THEN** 显示原文与明确解析失败或截断提示，提供下载，不将部分 JSON 作为完整结果
#### Scenario: 主动内容
- **WHEN** 文件是 HTML 或 SVG
- **THEN** 仅允许安全纯文本预览或下载，脚本不得执行
