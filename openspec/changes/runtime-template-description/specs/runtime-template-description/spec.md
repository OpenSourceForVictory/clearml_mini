## Purpose

让用户为客户端和服务端运行模板填写用途、适用场景及注意事项，在业务评测向导选择模板时能就近阅读这些信息，并保持旧模板和历史执行配置兼容。

## ADDED Requirements

### Requirement: 模板说明持久化
系统 SHALL 支持可选的多行纯文本模板说明，最大 2000 字符；创建、草稿编辑、复制和查看 SHALL 保留说明，省略字段时默认为空。

#### Scenario: 复制和编辑模板
- **WHEN** 用户复制带说明的模板并编辑新草稿说明
- **THEN** 新版本保留修改，原模板及既有执行快照不变

#### Scenario: 边界与历史兼容
- **WHEN** 提交超过 2000 字符的说明或读取未填写说明的历史模板
- **THEN** 超长输入被拒绝，历史模板按空说明读取且仍可使用

### Requirement: 选择时显示说明
系统 SHALL 在向导选中客户端模板或每个托管服务模板后，就近显示对应说明；未填写时展示“暂无模板说明”。

#### Scenario: 切换和自动恢复
- **WHEN** 用户切换模板或从集合及历史批次恢复模板选择
- **THEN** 说明随实际选中模板更新，清空选择后不残留上一个模板说明

#### Scenario: 安全完整展示
- **WHEN** 说明包含换行、长连续文本或 HTML 标签
- **THEN** 以可换行的纯文本展示，不执行 HTML，不遮挡窄屏操作

### Requirement: 说明不改变执行
模板说明 SHALL 不参与命令、环境变量、参数映射和调度，现有模板权限与版本规则 SHALL 保持不变。

#### Scenario: 说明包含占位符
- **WHEN** 模板说明写有业务参数占位符
- **THEN** 说明保留原文本，不改变执行命令和业务输入
