## Context
解除纳管保留 Worker/Slot，唯一的机器名及设备 UUID 阻止重用。历史运行、审计和清理记录均引用其 ID。
## Goals / Non-Goals
通过界面清理安装并删除登记后按原名重新注册，历史 ID 不转移到新机器。不删除模型、镜像、业务工作区、NFS 或系统账号。
## Decisions
Worker/Slot 增加 deleted_at；存活记录的机器名、设备 UUID、节点索引通过部分唯一索引约束，历史属性不改写。所有注册及资源列表只选择未删除记录；旧凭据持续无效，旧 ID 不可重新启用/重新纳管。
SSH 清理复用临时凭据、指纹和串行目标操作机制；计划列出 root 系统安装文件，校验配置身份及权限，未知路径或未完成执行/升级记录拒绝。确认时先取得平台清理许可阻止删除/重新纳管，再重检远端计划；停止管理组件和 Worker，将文件移入 root 私有备份并保存逐项清单，失败保持停用并显示备份位置，不自动重启。普通用户服务或无法证明归属的残留要求人工处理。
平台清理记录与执行器结果独立保存。执行中或失败不确定状态阻止删除；重试需重新检查。清理成功后仍需显式删除机器；删除平台记录不要求远端在线。
## Risks / Trade-offs
需先迁移数据库；降级前若有软删除记录需人工处理，避免恢复全局唯一约束时丢失历史。清理不承诺断电事务；部分移动保留清单以便恢复。不执行实际用户节点清理来代替隔离验证。
