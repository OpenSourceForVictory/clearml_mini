# Design

## Context

现有run-wizard.tsx集中管理草稿、步骤、预检序列和幂等键，ManagedServices、BusinessValues、ResourceRequest负责局部编辑。既有返回草稿、导入与提交回归需保留。浏览器核查发现服务资源折叠、复选框错位、确认遗漏服务实例数；390px页面未整页溢出但过长。23项现有浏览器回归通过是行为基线，不是新设计验收。

## Goals / Non-Goals

Goals：可理解的模块层级、完整确认、可追溯的生效值与可恢复的编辑流程。
Non-Goals：不增加执行快照表、不重写参数解析器、不调整调度或实例启动语义、不改结果页、不保存草稿到浏览器持久存储。无需新增依赖。

## Decisions

1. 保留五步，使用模块卡片而非增加步骤。模块内标题、摘要、必填提示和高级折叠保持一致；顶部可返回已完成步骤，不能绕过未完成步骤的校验。集中步骤导航函数保留现有seq失效及幂等机制。相比自由跳转，避免遗漏必填项。
2. 第一步常见字段保留任务名、回合、种子；标识、单项参数、资源和服务关联置于详情。集合只读摘要与可编辑清单分开，复用现有复制语义。长清单局部滚动，暂不引入分页或改变100项上限。
3. 客户端模块：模板卡（显示模式/协议/回合/失败策略）→业务参数→执行时限→环境变量。只展示API实际提供的信息，旧模板缺字段显示未声明而非推断。选择整任务普通命令即提示回合行为，保持现有提交规则。
4. 服务模块：来源选择→每个定义的独立卡片（模板、逻辑名称、实例数、资源池、访问模式）→参数→资源→高级环境/固定槽位→结束策略。服务资源池直接可见；跟随客户端显示具体名称或未选择。逻辑服务名与设备共享分开说明。
5. 第四步展示客户端资源池、资源、并发，并汇总服务资源提供返回链接，不引入第二份可编辑服务草稿。资源值标明最低预约与运行上限；模板锁定字段解释原因。
6. 环境编辑引入单一原始草稿及解析状态，键值表与JSON视图切换仅在有效JSON时完成。允许键以选择形式呈现；false/0等业务参数保留类型，环境仍严格为字符串值。禁止自动静默丢弃历史未知键；切换模板后显示不兼容提示。共享BusinessValues改动须回归模板复制等其他调用方。
7. 确认摘要复用当前草稿，预检后的最终参数/资源复用API effective_parameters、case_checks、service_plan。不在前端复制后端优先级算法。按任务展开差异；托管服务展示实例数和独立资源池。原始JSON作为诊断可选项，默认使用字段表。
8. 将诊断划分为配置、资源、环境、连通性四类；仅映射已有reason与明确证据，未知类别保留原文。地址available只表示分配资格。单次preflight失败不虚构候选设备；空态、请求失败和等待资源独立呈现。
9. 错误保存模块/字段定位信息；展开出错折叠区后聚焦字段。底部sticky操作栏保留占位和scroll-margin，限定向导容器内；checkbox使用独立样式避免全局input宽度污染。桌面1440/1024、窄屏390和键盘顺序分别验收。

## Risks / Trade-offs

- [旧模板和导入字段不完整] → 保留未知/缺失提示及原有导入确认，不以新默认值改写历史草稿。
- [UI重组导致参数丢失] → 相同配置的新旧提交payload作等价断言，覆盖服务多实例、单项覆盖、零值、不限及返回导航。
- [隐藏字段导致浏览器无法聚焦] → 模块级校验先展开定位，再阻止前进；不只依赖原生required。
- [上下文丢失] → 各步显示简短批次/任务数量摘要；不增加常驻大侧栏占用宽度。
- [只读摘要显示与后端不一致] → 未预检标为待解析；有效数据只用后端结果，修改即失效。
- [测试覆盖率误述] → 浏览器通过数不折算代码覆盖率；Python若涉及改动采用统一统计工具，保留失败及跳过。

## Migration Plan

纯前端与指南变更，无数据库迁移和Worker/Runner升级。先相关浏览器回归和构建，再真实平台草稿核查及截图；测试提交仅在受控测试环境进行，不从核查页面启动业务。记录旧前端镜像并通过现有部署方式更新，出现回归可回退前端；API契约保持兼容。

## 资源配置布局补丁

资源池及并发保持双列；完整资源要求与高级约束跨整行，资源要求内部桌面双列、窄屏单列，字段来源随字段展示。样式仅作用向导；不改资源默认值、权限、参数映射和调度。补测有资源契约与旧模板两条路径，避免只验客户端步骤而漏掉第四步。

实际补测发现第四步底部 sticky 操作栏会遮住恢复默认按钮；资源步骤操作栏改为正常文档流，随表单结尾显示，其他步骤保持现有导航。用浏览器几何断言验证末字段及恢复按钮不与操作栏相交。

用户明确报告“修改服务端资源”长条：服务摘要 aside 误匹配全局导航样式。导航样式限定 .shell > aside，服务摘要使用具名 section 普通卡片；补托管服务三屏宽测试，检查非 fixed、卡片边界、实例数及独立池、返回服务步骤。
