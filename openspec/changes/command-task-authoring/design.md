# Design
客户端模板显式task_type，command强制direct和episode_reporting=false；切回evaluation恢复原评测接入草稿。服务端不显示任务类型。只读配置及复制保留类型。帮助说明普通命令无需SDK或结果JSON，执行方式仍支持Docker/host。
向导选择普通命令时默认none，切回评测将none恢复external；用户仍可显式为普通命令选择服务。自定义任务与新集合command提交episodes=1，界面解释每项一次、不统计回合；已有集合不偷偷修改持久化数据。集合编辑选择普通命令时禁用回合编辑并保存兼容值1。发布、排队、退出码判定沿用后端实现。
验证模板Docker/host提交、类型往返、服务端不受影响、普通命令无需服务提交、集合回合兼容值及已有评测回归。静态发布并提交代码。
