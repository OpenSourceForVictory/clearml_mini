# Design

## Context

见 proposal.md。Templates 当前用内联 details/pre 展示 JSON；TemplateForm 分组录入，ParameterEditor 和 MountEditor 保存复杂草稿。已有复制测试验证 schema 和 mounts 保留。

## Goals / Non-Goals

帮助首次注册并让配置可读；只读视图准确表达已有值。此次不改执行协议、不自动安装业务依赖、不为示例创建生产任务。

## Decisions

1. 使用独立 TemplateHelp 组件按 kind/mode/integration 展示指引，基础步骤默认可见，详细示例折叠。优于单独文档链接，用户无需离开表单。
2. 示例只展示、供手动参考，不自动填充或覆盖草稿。命令用有效 JSON argv；标注示例脚本/镜像需要用户准备。SDK 示例说明每回合结果文件，direct 说明完整任务协议；服务端说明监听端口和健康检查。业务参数使用 scene 等非保留字段，说明 input/argv/env 三种绑定及来源。
3. 查看使用结构化只读组件，与注册共用分组标题、字段标签、解释和格式化工具，不直接复用带提交副作用的编辑表单。保持清晰对比度和文本可选中，避免整页 disabled 控件难读。复杂参数按字段显示类型、默认值、约束、绑定及覆盖权限；挂载显示逻辑来源、目标、读写和必需状态。
4. 模板特定分组按实际模式展示；缺省值标为未配置/默认并与显式值区分。表单未覆盖的 platform_bindings、设备等现有字段提供补充配置区域，原始 JSON 可折叠查看，不丢失原数据。
5. 查看有独立关闭入口和复制新版本入口，复制复用原 source 对象，不能从展示文本反序列化；查看不提供保存且不发写请求。
6. 保留客户端/服务端上层页签，增加已注册模板/注册新模板下层页签，各 tablist 使用不同可访问名称。表单草稿由父级分类型保留，切换列表不重置；注册成功回到对应列表并刷新。复制已有模板若会替换当前非空草稿，先提示确认，取消则原草稿保留。查看配置留在列表页签，不与新建表单混排。

## Risks / Trade-offs

- [示例与真实协议不一致] → 对照 docs/runtime-templates.md、runner 实现核实占位符和结果格式；示例标记依赖，不能冒充可直接运行的内置环境。
- [共享编辑器影响其他页面] → 帮助优先限定模板入口，检查复制草稿、集合业务参数、机器挂载配置调用方并回归。
- [帮助内容过长] → 基础说明短句、详细示例折叠，桌面和窄屏检查。
- [当前稳定性验收被部署中断] → 开发和预览隔离；生产发布待持续测试结束，并按既有发布步骤验证入口。

## Migration Plan

无需数据库迁移。完成前端类型检查、构建、模板及相关流程浏览器回归；记录截图和真实界面检查，提交代码。生产使用新版前端制品，失败恢复前一镜像；报告区分开发完成与实际上线。
