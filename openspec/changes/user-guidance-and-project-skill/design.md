## Context
已有模板内提示和散落 Markdown，但无统一界面指南。Python SDK 在 runner/sdk.py，命令包装器在 runner/command_sdk.py，直接协议使用 stdout 事件与最终指标。须保持既有表单状态和调度语义。
## Goals / Non-Goals
在界面阅读、检索操作与接入说明，并下载离线接入材料。Agent 使用仓库 Skill 查询真实实现。不新增协议、调度器或凭据管理。
## Decisions
- 统一类型化主题目录，页面上下文与全局指南复用同一内容。全局指南用原生 dialog 打开，关闭恢复焦点，不卸载表单；不用另一个独立文档网站。
- 页面操作帮助对应主题映射，包含操作步骤、结果语义、异常修复，管理员主题在成员视图隐藏。
- SDK 包从 runner 源码构建为确定性 ZIP，附三种客户端样例、本地输入与自检。界面下载，不要求用户克隆仓库；包不包含 Worker、部署凭据和运行数据。
- Skill 引用模块索引与现有文档，不复制整套用户说明。AGENTS.md 强制每次代码修改同步相关说明。
## Risks / Trade-offs
- 文档漂移 → 主题入口覆盖、SDK 源码一致性及样例执行测试，提交检查。
- 帮助破坏表单 → 模态帮助不切换工作区，测试关闭后草稿和键盘焦点。
- 模拟样例误解 → 显式标记非真实模型评测，失败回合和进程异常分开说明。
## Migration Plan
无数据库迁移；前端构建包含 SDK 静态包，API 镜像发布。检查线上指南和下载；可回滚原镜像。
