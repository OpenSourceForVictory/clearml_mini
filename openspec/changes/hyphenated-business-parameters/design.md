## Decisions
业务名首字符仍为字母，后续允许字母数字下划线中划线，最长64；环境名首字符字母或下划线，后续增加中划线，最长128。独立 BUSINESS_NAME 避免放宽资产路径校验。业务 JSON 键原样保留，不将中划线转成下划线。argv/env 通过现有字典和 argv 传递，无 shell 插值。环境保留名称、大小、NUL 与覆盖权限不变。登录 shell 自己导出的环境保持已有解析，不承诺 shell 能 export 非标识符名称；页面说明 Python getenv 可读取，shell 可能丢弃此类名称，推荐 shell 使用下划线。
## Validation
共享契约正常/边界/拒绝路径、真实本地子进程获取 argv/env、前端动态映射和保存、原有模板回归。不声称真机模型或完整覆盖率已验证。
