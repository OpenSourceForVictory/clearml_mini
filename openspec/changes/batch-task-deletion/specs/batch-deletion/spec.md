# 批次删除

## ADDED Requirements

### Requirement: 删除批次必须清理批次任务

删除请求通过终态、清理确认和服务停止检查后，系统 MUST 删除该批次的任务、运行尝试、日志、回合记录、产物、执行数据和关联编排服务实例；系统 MUST 保留批次删除墓碑和管理审计记录。

#### Scenario: 已结束批次删除任务

- **WHEN** 所有任务已终态、所有运行清理已确认且关联服务已停止
- **THEN** 删除请求成功，批次任务查询返回不存在，批次墓碑标记为已删除，审计记录仍可查询

#### Scenario: 未完成任务拒绝删除

- **WHEN** 批次仍有活动任务或未确认清理的运行
- **THEN** 删除请求返回 409，任务和批次均保持不变

#### Scenario: 删除请求重复提交

- **WHEN** 同一批次已删除后再次提交删除请求
- **THEN** 请求幂等成功，不能恢复或重新创建已删除任务
