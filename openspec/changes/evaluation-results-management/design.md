# Context
批次数据按20条分页，已有监控、比较、控制和编排服务接口。
# Goals / Non-Goals
改善浏览与删除历史记录；不改变调度策略、不删除宿主机数据、不自动停止外部推理服务。
# Decisions
独立结果列表组件；概览及筛选明确仅当前页，保留跨页比较及详情深链接。回合进度仅使用上报数据，不把任务结束当作目标成功。
增加 EvaluationBatch.deleted_at，DELETE持有调度锁并校验所有任务终态、所有尝试cleanup_confirmed，以及关联服务desired_running=false且没有占用。授权同批次控制，删除重复请求幂等；列表隐藏、详情/监控/报告/编排返回404，幂等提交不能复活删除批次。单任务重试也拒绝已删除批次。保留任务审计数据与文件，不物理删除。
确认框说明删除范围，接口409保留记录并展示原因。删除后移除比较选中项，末页空则回前页。
# Risks / Trade-offs
逻辑删除不释放存储空间，界面明确说明。锁与重试、控制、服务启停共用以避免竞态。数据库迁移为可空列兼容旧代码，部署先迁移再重启API。
# Validation
API覆盖权限、活跃/未清理/服务占用拒绝、幂等、删除后读写保护、保留日志；浏览器覆盖筛选、长标题窄屏、确认取消/失败/成功、分页和比较回归。类型检查、构建、生产只读验证。

## 表格展示调整
按用户反馈，将批次卡片改为每批次一行的语义表格。名称截断并支持悬停查看全文，提交时间、状态、并发、任务进度、回合进度和操作各自对齐列。窄屏在表格内横向滚动，不将行转换为卡片；保留所有比较和删除行为。

结果页面增加“运行记录”和“评测任务集合管理”子页签，复用SuiteManager及当前用户权限；集合页按需挂载，切换保留草稿，从集合发起运行时将选中集合传给业务评测向导。
