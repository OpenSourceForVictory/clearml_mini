## Why

宿主机任务启动时先写入 `CUDA_VISIBLE_DEVICES`，再合并任务环境。API 已拒绝保留变量，但 Worker 对收到的任务覆盖值没有再次校验；若任务快照异常，平台分配设备可能被覆盖。

## What Changes

- Worker 再次校验宿主机任务环境覆盖值及模板允许覆盖列表。
- 合并业务变量后才写入平台分配的 GPU 可见设备；NPU 保持最后设置逻辑设备 0 和设备访问限制。
- 增加正常、保留变量及未批准覆盖的边界测试，更新启动环境说明。

## Impact

仅改变 Worker 对异常宿主机任务快照的拒绝行为与 GPU 设备环境的最终赋值；正常模板、API、数据库和纳管配置不变。
