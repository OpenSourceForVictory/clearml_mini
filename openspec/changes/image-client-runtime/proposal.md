# Proposal
## Why
用户已有仿真镜像仍需管理员手工注册且无法声明启动变量和逻辑资产。不同节点实际目录应由平台映射，用户不应为每台机器修改客户端。
## What Changes
- 用户注册私有镜像客户端，声明命令、变量默认值/可覆盖项、容器工作/结果路径与逻辑资产目标。
- 管理员版本化配置节点批准镜像和逻辑资产宿主路径，Worker 验证并报告可用性；不自动拉取或登录仓库。
- 协议 v5 支持运行配置快照、调度准入与可见等待原因，旧模板/Worker 兼容。
- 为已有 Python 镜像注入标准库平台适配层，无需镜像预装 runner；客户端须按既有事件/指标协议回报结果。
- 完成界面、双机隔离 Docker 验收和正式上线。
## Capabilities
### New Capabilities
- image-client-runtime: 用户镜像、启动变量、逻辑目录和节点就绪管理。
### Modified Capabilities
无。
## Impact
模板/机器/槽位模型、迁移、Worker/Runner、调度与查询 API、客户端和机器管理页面。无新外部服务或库依赖。
