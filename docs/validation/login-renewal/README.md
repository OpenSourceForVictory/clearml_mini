# 活跃登录续期验证

## 修改与边界

固定 30 分钟 JWT 会让持续操作的用户退出并卸载表单。现在登录签发原始起点，续期不改变该起点，过期或异常令牌不可续期，单次登录最长 12 小时。前端真实交互触发节流续期，后台轮询不延长会话。过期隐藏但保留当前工作台，同账号同角色登录可恢复；显式退出清空。页面刷新、关闭不保证保留草稿。

旧 JWT 无起点，需要重新登录；后端和前端需配套发布。未发布到用户外部平台；远端纳管故障仍需检查节点服务及配置。本验证不涉及真实模型质量。

- 后端会话专用回归 13 项通过，覆盖连续续期、12 小时边界、缺字段、失效、签名异常、禁用/不存在账号。
- 浏览器 18 项通过（登录会话、管理页、指南及设备标签相关用例），使用模拟 API 和浏览器时钟。包含真实交互/轮询区别、闲置、服务端到期、隐藏页面、401、网络错误、同账号草稿恢复、不同账号拒绝、旧响应隔离和退出。
- TypeScript 检查和 Vite 构建通过。Vite 保留大于 500 kB chunk 提示，未调高警告阈值。
- OpenSpec 严格校验和 diff 空白检查通过。
- 前端没有行/分支插桩，浏览器通过数不能作为覆盖率。Python 独立子进程未合并的覆盖率也不作声明。

## 失败证据

初始浏览器 mock 将 jobs 列表错误设为对象，已修正；后续用例在续期/登录响应落地前推进时钟或检查字段，出现过期与隐藏表单重复匹配。修正为等待令牌落地及登录页关闭，未放宽业务断言。首次及中间运行日志保留于 `.runtime/login-renewal/`，最终通过记录为 `browser-complete.log`。测试服务器和数据库均为独立环境，未在生产库运行测试。
