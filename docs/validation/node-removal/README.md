实现范围：已解除纳管机器软删除及身份重用；标准 root 节点残留检查、SSH 确认、私有备份与回执恢复；纳管确认更新登录令牌。

验证边界：测试使用临时 SQLite、一次性 PostgreSQL、临时文件、模拟 SSH/systemctl 和浏览器 API 拦截。未连接用户 SSH 节点，未删除用户机器或业务数据，未执行真实模型/GPU/NPU 验收。前端及未插桩独立进程不在 Python 覆盖率中。

- 固定最终实现后的纳管相关 Python 回归 94 项通过；针对性回归覆盖历史引用、无权/版本冲突/活动执行/升级保护、旧 ID 不可恢复、SSH 计划变化、孤立 service、恢复记录/路径/权限保护、部分失败备份、401 后回执核对及确认前回执保留。
