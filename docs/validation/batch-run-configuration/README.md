## 自动化与失败记录

专项 Playwright 覆盖向导分组、客户端及多服务名称、命令、模式、参数来源与逐任务切换、0与缺失值、旧实例上限、外部/无服务、空批次、无快照、失败重试、乱序响应、跨批次切换与小屏布局。回归批次监控、配置入口和服务状态页。

初轮失败包括：断言误把应用初始化的模板列表请求当成配置页请求；缺失值断言误匹配说明文字中的“不限制”；旧配置页测试仍寻找已改为实例表格的服务标题。已分别限定请求观察范围、检查实际字段及断言服务实例行，保留日志 `/tmp/batch-config-tests.log`、`/tmp/batch-config-regression.log`。没有通过删除用例规避问题。

最终22项Playwright专项及回归通过，TypeScript和Vite构建通过；本地日志 `/tmp/batch-config-final-tests.log`、`/tmp/batch-config-final-build.log`、`/tmp/batch-config-live-final.log`。前端未插桩，不宣称全仓或Python覆盖率。Vite保留现有大于500kB构建块提示；未调整警告阈值。
