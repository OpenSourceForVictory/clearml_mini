一轮 50 任务预检返回 `ready`，50 项均可配对；提交 201、150 ms，在服务启动阶段取消 200、21 ms，50 项全部取消。第二轮提交 201、157 ms，等待至 2 项运行、2 项启动中、46 项排队后取消 200、43 ms；4 项收到取消请求，46 项直接取消。其后 4 个 50 任务批次并发提交，共 200 项，全部返回 201，单次耗时 160–433 ms；并发整批取消全部返回 200，单次耗时 20–77 ms。七个压测批次最终都收敛到 50/50 `CANCELLED`，没有残留运行项。用于页面参数回填验证的再次运行批次也已主动取消。
