# 数据同步独立展示验收（4.5）

批次任务行和执行尝试详情分别展示程序执行、平台协议回合结果和数据同步状态。恢复协议的同步状态来自原执行的控制快照；正常完成、待同步、失败与拒收原因、五分钟后延迟和日志缺口各自显示。旧执行明确显示“历史执行”，不会被当作同步完成。程序退出码 0 不会把缺失或失败的协议结果改成成功。

验证口径：`backend/tests/test_result_sync_view.py` 覆盖正常、终态待同步、恰好五分钟与超过边界、失败原因、日志缺口、旧执行和监控/尝试详情一致；`backend/tests/test_recovery_finish.py` 覆盖最终封口与缺结果失败；`frontend/tests/batch-monitoring.spec.ts` 覆盖四种同步状态、延迟、缺口、程序/回合独立展示及历史尝试。前端使用 mock API，后端使用隔离测试库；未把浏览器测试说成真实断联节点或模型评测。生产恢复能力仍关闭，真实断联批次页面验收仍属 5.3。
