## 已部署与未启用的边界

- 本机 API 镜像为 `mini-eval-api:log-recovery-3216ae0`，数据库 `b03a7b8`；local4090-151 Worker 已按界面同 API 升级。其他节点未全部升级。
- 最新日志窗口已验证宿主机/Docker 各退出0/1、最新尾部与截断提示；SDK成功/业务失败及CUDA算子另有真实批次。共4批次7个真实进程，不是模型质量或断联恢复验收。
- `worker/version.py` 尚不宣告 `disconnected_execution_v1`；`execution.py` 的新分配要求 `RECOVERY_EXECUTION_ENABLED` 及能力匹配。生产完整恢复能力仍关闭。不要只开启开关绕过剩余验证，也不能承诺当前旧执行已获得无限断联容忍。
- `Worker.execute` 已分派到 recovery_execution；过去“正常执行主循环没接通”的阶段说明已过时，缺口是剩余处理与验收，不应重做整条链路。
