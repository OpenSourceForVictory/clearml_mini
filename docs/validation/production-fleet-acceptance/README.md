## 本轮发现及修正

- 升级成功和 Agent 配置应用回执存在短暂先后关系：发布工具改为有期限地等待就绪，并按确切升级 ID 对账，未重复安装。
- 旧冒烟脚本仍读取单执行 journal：显式使用隔离状态目录并按任务匹配多执行 journal 后通过真实重启验收。
- 测试回显程序最初遗漏 SDK 要求的逐回合结果 JSON：旧失败批次保留，模板新版本补齐结果文件，新增实测回显契约用例后重跑矩阵。
- 浏览器测试最初只匹配“提交排队”，而资源就绪显示“提交评测批次”：改为覆盖两种合法文案，生产页面复测通过。
- 失败重试测试最初试图在容器只读缓存目录写标记：保留失败记录，改为批准的宿主机测试环境写独立测试标记，三项补跑成功；没有放宽容器挂载权限。

CPU/RAM 瞬时压力、过期采样和慢 I/O 由隔离注入验证，没有耗尽生产内存、关闭整机网络或重启 Docker daemon。通过的测试不能替代真实 RoboTwin 模型质量评测，也不代表长期零故障承诺。
