# 计算资源角色视图验证

“计算资源”新增全部、客户端、服务端三个分类；按 Worker.roles 筛选，双角色设备在全部中只计一次。管理员明细含角色，普通用户保持 total/online 汇总权限；无 Worker 的旧设备按客户端处理。资源池仍列全平台可用池。

验证：`test_resource_roles.py` 检查专用客户端、专用服务端、双角色、旧槽位和非法参数；`resource-roles.spec.ts` 两项浏览器测试检查管理员与普通用户切换、计数和权限。浏览器连同节点管理/指南回归共 10 项通过、3 项需要真实环境的 workbench 用例跳过。TypeScript 与 Vite 构建通过，保留已有的 500 kB 包大小提示。
