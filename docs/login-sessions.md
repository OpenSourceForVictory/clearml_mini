# 登录会话与自动续期

登录后，点击、键盘输入、触摸和滚轮操作会触发节流续期（每分钟最多一次）；后台轮询、自动刷新数据和程序生成的事件不算用户活跃。浏览器隐藏时不续期。

登录令牌有效期为 30 分钟，续期保留原登录时间，单次登录最长 12 小时。浏览器也检查连续闲置时间；达到 30 分钟或令牌先过期时隐藏工作台并提示重新登录。由于续期节流，最后一次操作后的剩余有效期可能比 30 分钟短最多约一分钟；以令牌有效期为准。到期前两分钟显示提示，满 12 小时必须重新登录。

过期后，当前已挂载页面的表单保留在内存中。同一账号、同一角色重新登录后继续操作；不会自动重新提交失败请求。账号不同或角色已变更时，先选择“退出并清除当前草稿”，再重新登录。主动退出会清除当前工作台。刷新或关闭页面不保证保留表单，SSH 密码、令牌和私钥不会作为草稿持久化到本地存储。

续期网络错误不会立即清除表单；后续用户操作会再次尝试，最多每分钟一次，单次请求超时 10 秒。令牌失效仍需登录。多个标签页各自使用 sessionStorage 和独立活动计时，操作一个标签页不保证其他标签页续期。

## 后端接口与边界

- `POST /api/v1/auth/login`：验证账号密码，返回带 `session_started_at` 和 `exp` 的 Bearer JWT。
- `POST /api/v1/auth/renew`：使用当前未过期 JWT；校验账号存在且启用、有效的原始登录时间、12 小时上限。返回新 `access_token`；不接受已过期或缺少会话起点的旧 JWT。无需数据库迁移。
- 普通 API 访问不延长有效期。续期后旧令牌保持原到期时间；本实现不增加服务端会话注销表或长期刷新凭据。
- 旧版本登录令牌仍可在原有效期内使用，但首次续期会要求重新登录；重新登录后使用新规则。前后端需配套更新。
- 节点 Agent、Worker 和升级执行器使用独立机器凭据，不受用户登录续期规则影响。

## 验证范围

后端测试覆盖正常签发、连续续期保留起点、绝对上限、过期/缺少字段/异常字段/篡改签名/禁用及不存在账号。浏览器使用模拟 API 与时钟验证操作续期、轮询不续期、草稿恢复、账号隔离、网络错误和并发响应。2026-11-17 本机平台容器已发布，见[发布记录](validation/login-renewal/README.md#2026-11-17-本机平台发布)；模拟浏览器测试不等于真实用户浏览器验收，前端未插桩，不能以测试数量替代覆盖率。
