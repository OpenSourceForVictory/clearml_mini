# 评测与管理页面

- **我的任务**：查询任务记录、筛选状态、打开详情及结果；不再提供提交表单。
- **业务评测向导**：选择或创建任务清单，配置客户端、服务端和资源，预检后提交。
- **评测运行与结果**：按提交批次查看状态；查看批次可读取本次任务参数、服务端参数和状态、任务运行位置、逐回合结果、日志与产物。参数来自运行快照，不是当前模板。
- **管理设置 → 评测集合管理**：管理集合版本，发布并运行将带入业务评测向导。
- **管理设置 → 运行模板管理 → 镜像与代码接入**：登记自有镜像、提交代码构建及复制个人模板。普通成员通过左侧“评测配置”使用自己的集合和客户端配置。
- **管理设置 → 机器管理 → 查看配置**：基本配置、节点 Agent、版本升级、宿主机环境、工作目录与资产、容器环境、数据保留、服务网络（仅服务端）分别显示。页内切换保留未提交值，切换机器或刷新页面不保证草稿保留。
- **运行模板 → 查看配置**：与注册表单一致的只读布局；需修改时点击“以此配置创建新版本”。原始 JSON 保留供核对未在表单中呈现的补充字段。

旧批次详情和比较链接继续有效，返回批次列表进入“评测运行与结果”。页面调整不修改后台评测接口、历史记录或调度行为。
