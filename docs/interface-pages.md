# 评测与管理页面

- **我的任务**：查询任务记录、筛选状态、打开详情及结果；不再提供提交表单。
- **业务评测向导**：选择或创建任务清单，配置客户端、服务端和资源，预检后提交。
- **评测运行与结果**：按提交批次查看状态；查看批次可读取本次任务参数、服务端参数和状态、任务运行位置、逐回合结果、日志与产物。参数来自运行快照，不是当前模板。
- **管理设置 → 评测集合管理**：管理集合版本，发布并运行将带入业务评测向导。
- **管理设置 → 运行模板管理 → 镜像与代码接入**：登记自有镜像、提交代码构建及复制个人模板。普通成员通过左侧“评测配置”使用自己的集合和客户端配置。
- **管理设置 → 机器管理 → 查看配置**：基本配置、节点 Agent、版本升级、宿主机环境、工作目录与资产、容器环境、数据保留、服务网络（仅服务端）分别显示。页内切换保留未提交值，切换机器或刷新页面不保证草稿保留。
- **运行模板 → 查看配置**：与注册表单一致的只读布局；需修改时点击“以此配置创建新版本”。原始 JSON 保留供核对未在表单中呈现的补充字段。

旧批次详情和比较链接继续有效，返回批次列表进入“评测运行与结果”。页面调整不修改后台评测接口、历史记录或调度行为。

## 评测运行与结果：浏览和删除

“评测运行与结果”包含“运行记录”和“评测任务集合管理”两个子页签。运行记录使用每批次一行的表格展示状态、提交时间、并发数、任务完成进度和已上报回合；长名称截断并可悬停查看全文，窄屏在表格内横向滚动。集合管理复用导入、创建、编辑、发布和运行功能，切换页签保留编辑草稿，点击运行将集合传入业务评测向导。顶部概览、搜索和状态筛选只针对当前页（每页最多20条），比较仍支持跨页选择两个批次。任务执行成功不等于全部回合目标成功；回合统计仅使用当前执行尝试的实际报告，详细结果进入“查看批次”。

已结束批次可点击“删除批次”，核对提示后确认。运行中的批次应先进入详情取消整批；等待任务和关联平台服务停止、所有执行尝试确认清理后才能删除。关联服务若配置为保留运行，需要在详情主动停止。服务器会再次检查状态和权限，不能仅凭页面上的终态绕过检查。

删除为逻辑删除：从批次列表移除，批次详情、报告、比较和补跑不可用；“我的任务”中的历史任务、日志、产物和审计记录保留，不释放磁盘空间。删除后的单任务重试和关联服务重启也被拒绝。重新运行请通过业务评测向导新建批次。删除同一批次的重复请求幂等。
